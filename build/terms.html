2. Description of Service & Features

SideNote is a productivity browser extension engineered for Chromium-based browsers that provides local-first note-taking and voice memo recording directly within Google Chrome's native side panel. The Service includes, without limitation:

  • Side Panel Workspace (sidepanel.html): A dockable, non-intrusive container displaying notes, audio controls, and rich text editors alongside active web tabs.
  • TipTap Rich Text Editor: In-browser formatted text editing, supporting lists, headings, code blocks, and quote styling.
  • Google Keep Color Palettes: Authentic pastel palettes (Sand, Mint, Storm, Coral, Dusk) for organizing and prioritizing your notes.
  • Voice Memo Recording & Playback: In-browser audio recording utilizing the Web Audio API (getUserMedia) with integrated waveform visualization and local playback.
  • All-Notes Masonry Dashboard (all-notes.html): A multi-column visual manager for searching, filtering, and organizing notes across all visited domains.
  • Settings & Diagnostics (settings.html): Microphone diagnostics, storage quota metrics, and personalization preferences.
